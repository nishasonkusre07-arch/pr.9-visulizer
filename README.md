# 📊 Data Analysis & Visualization Program

## 🌟 Project Overview

This project is a **Data Analysis and Visualization Program** developed using Python.
It provides a simple menu-driven system to load a sales dataset, explore data, perform DataFrame operations, handle missing values, generate descriptive statistics, and create different types of visualizations.

The project is useful for understanding the basic concepts of **Data Analysis, Pandas, and Matplotlib**. 📈🐍

---

## 🎯 Project Objectives

The main objectives of this project are:

* 📂 Load and work with a sales dataset
* 🔍 Explore and understand the dataset
* 📊 Perform different DataFrame operations
* 🧹 Handle missing or null values
* 📋 Generate descriptive statistics
* 📈 Create different types of charts
* 💾 Save generated visualizations
* 🖥️ Provide all features through a simple menu-driven program

---

## 🛠️ Technologies Used

### 🐍 Python

Python is used as the main programming language for developing the project.

### 🐼 Pandas

Pandas is used for:

* Creating the dataset
* Managing tabular data
* Exploring rows and columns
* Sorting and filtering data
* Grouping data
* Handling missing values
* Generating statistical information

### 📊 Matplotlib

Matplotlib is used to create different visualizations from the dataset.

## 🚀 Main Features

### 1️⃣ Load Dataset

The program loads the sales dataset and displays the available records.

It includes information about:

* Sales ID
* Product
* Region
* Sales
* Year

After loading, the program displays a confirmation message and the dataset. 📂📊

---

### 2️⃣ Explore Data 🔍

The Explore Data section helps users understand the dataset.

Available options include:

* 👀 Display first 5 rows
* 🔚 Display last 5 rows
* 🏷️ Display column names
* 🔢 Display data types
* ℹ️ Display basic information

This feature helps users quickly understand the structure of the dataset.

---

### 3️⃣ DataFrame Operations 📊

The project provides different operations for working with DataFrames.

Users can:

* ↕️ Sort data
* 🔎 Filter data
* 🌍 Group data by Region
* 📦 Group data by Product

These operations help in analyzing sales data and finding useful information from the dataset.

---

### 4️⃣ Handle Missing Data 🧹

The project provides options to manage missing values in the dataset.

Users can:

* 🔍 Display rows containing missing values
* ➗ Fill missing numeric values using the mean
* 🗑️ Remove rows containing missing values
* ✏️ Replace missing values with a specific value

This helps maintain better data quality before performing analysis.

---

### 5️⃣ Descriptive Statistics 📋

The project can generate descriptive statistics for the dataset.

This helps summarize numerical data and understand important statistical information such as:

* 🔢 Count
* 📉 Minimum value
* 📊 Average-related statistics
* 📈 Maximum value

The feature uses the dataset to provide a statistical summary.

# 📈 Data Visualization

One of the main features of this project is data visualization.

The program provides **six different types of charts**:

### 📊 1. Bar Plot

A bar plot is used to compare values between different categories.

It can be created by selecting an X-axis column and a Y-axis column.

---

### 📈 2. Line Plot

A line plot is useful for showing changes and trends between data points.

Users can select the required X-axis and Y-axis columns.

---

### 🔵 3. Scatter Plot

A scatter plot is used to show the relationship between two numerical variables.

The user can select two columns to create the scatter plot.

---

### 🥧 4. Pie Chart

A pie chart represents the distribution of values among different categories.

It displays category proportions using percentages.

---

### 📊 5. Histogram

A histogram shows the frequency distribution of numerical data.

It helps understand how values are distributed across different ranges.

---

### 📚 6. Stack Plot

A stack plot is used to display multiple data series together.

It helps compare different values across records and understand their combined contribution.
